## Overview

Horsepower Financial is a fintech application built with .NET Core and Razor. It presents cash-flow information based on data supplied by the user.

This case study covers professional work delivered in a fintech product context. Public website and repository links are not available.

## Problem

Financial users need a clear view of cash flow from the data they provide. The product addresses that need inside a fintech application surface.

## Solution

The application is implemented as a .NET Core and Razor web system with a KnockoutJS-influenced client UI approach, showing cash-flow views derived from user-provided data.
